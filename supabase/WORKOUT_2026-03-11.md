# Chest, Shoulders & Triceps

Exercise reference for the seed script.

---

## CHEST (Grudi)

| Exercise | Notes | Sets |
|----------|-------|------|
| **Drop set** | 3 sets × 2 reps | 3 × 2 |
| **Chest press** | Burst press | 12×9kg, 12×14kg, 12×18kg |
| **Bench with dumbbells** | Skip sometimes | 12×10, 12×10, 12×12.5kg |
| **Butterfly** | | 12×9, 12×14, 10×18kg |

---

## SHOULDERS (Ramena)

| Exercise | Notes | Sets |
|----------|-------|------|
| **Lateral raise** | Use lighter weight or skip | 12×3, 12×4, 12×5kg |
| **Shoulder press** | Machine 1. Or Henry Cavill raises as alternative | 12×9, 12×18, 12×18kg |
| **Henry Cavill raise** | When no shoulder press free, or as 3rd exercise | 12×5, 12×6, 12×7kg |
| **Cable machine lateral** | Machine 2. Drop sets | 9→14→18→23, 14→18→23→27, 18→23→27→29.5kg |

---

## TRICEPS (Triceps)

| Exercise | Notes | Sets |
|----------|-------|------|
| **Triceps pushdown** | First cable | 12×4.5, 12×9, 12×13.5kg |
| **Triceps overhead extension** | Above head | 12×4.5, 12×9, 12×13.5kg |
| **Skull crusher** | Barbell behind head. Skip first set 2nd time | 12×4/5/5, 12×5/6/6, 12×6/7/7 (drop) |
| **Seated triceps push machine** | New machine, sitting and pushing | 12×14, 12×18, 12×23kg |

- Sprava = Machine
